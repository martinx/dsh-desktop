说明

关于这个站点和这些构建

来源

所有安装包由 GitHub Actions 直接从 deepseek-ai/deepseek-harness 的源码编译，未修改代码。构建脚本和本站源码在 martinx/dsh-desktop，可自行核对。

非官方

本站与 DeepSeek 无隶属或背书关系。「DeepSeek Harness」是 DeepSeek 的商标，此处仅用于说明来源。上游以 MIT 许可证发布。

为什么不签名

Apple Developer ID 签名与公证需要付费开发者账号，且上游的发布流程绑定其自托管签名机器，无法在公开 CI 复现。因此这里只提供未签名的开发构建。
