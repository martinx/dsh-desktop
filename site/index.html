1

下载并安装

macOS 下载 .dmg 后双击挂载，把 DeepSeek Harness 拖进「应用程序」；Windows 运行 .exe 安装包。

2

清除隔离 / 绕过 SmartScreen

macOS 首次启动会被拦截，复制下方命令在终端执行一次；Windows 在提示中点「更多信息 → 仍要运行」。

3

开始使用

没有自动更新：升级请回到这里下载新的安装包，覆盖安装即可。

macOS xattr -dr com.apple.quarantine "/Applications/DeepSeek Harness.app"

说明

关于这个站点和这些构建。

安装包从哪来？

全部由 GitHub Actions 直接从上游 deepseek-ai/deepseek-harness 的源码编译，不修改代码。构建流程与本站源码都在 martinx/dsh-desktop，可自行核对。

这是官方发布吗？

不是。本站与 DeepSeek 无隶属或背书关系。「DeepSeek Harness」是 DeepSeek 的商标，此处仅用于说明来源；上游以 MIT 许可证发布，本项目同样使用 MIT。

为什么不签名？

Apple Developer ID 与公证需要付费开发者账号，Windows 代码签名需要 EV 证书，且上游的发布流程绑定自托管签名机器，无法在公开 CI 复现。因此这里只提供未签名的开发构建。

怎么更新？

未签名构建不包含自动更新器。回到本页下载最新的 nightly 或版本安装包，覆盖安装即可，数据保存在用户目录不受影响。

支持 Linux 吗？

暂不支持。上游打包流程只定义了 mac-arm64、mac-x64、win-x64 三个构建目标，没有可用的 Linux 产物管线。
